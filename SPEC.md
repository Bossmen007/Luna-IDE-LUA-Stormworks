# SPEC.md — Луна IDE (русская среда разработки Lua для Stormworks)

Полностью на русском языке, работает **офлайн**: настольная версия (`.exe`) и веб-версия
(открывается двойным кликом по `index.html`). Разработчик — СтаричЁк.

## 1. Цель и ценность
- **Главная задача:** дать русскоязычному игроку Stormworks возможность писать,
  запускать и отлаживать Lua-скрипты для микроконтроллеров, не зная английского.
- **Пользователь:** игрок/инженер Stormworks, знакомый с Lua или новичок.
- **Критерий приёмки:** пользователь открывает `index.html`, пишет скрипт с
  `function onDraw() ... end`, жмёт «Запустить» — видит результат на виртуальном
  мониторе, вывод `print()` в консоли, справочник API и уроки на русском.
- **Что НЕ входит в MVP:** регистрация/аккаунты, серверная часть, публичная галерея
  скриптов (заменяется ссылкой-шарингом), запуск «миссионного» Lua, реальный HTTP.

## 2. Стек
- Статический сайт: **HTML + CSS + JavaScript (ES5/ES6, без сборки)**, работает с `file://`.
- Редактор: **CodeMirror 5.65.16** (локально, режим Lua) — подсветка, номера строк,
  автоскобки, поиск/замена, сворачивание кода.
- Исполнение Lua: **Fengari-Web 0.1.4** (Lua 5.3, компилируется в JS) — локально, офлайн,
  виртуальная машина + hook для защиты от бесконечных циклов.
- Хранение: **localStorage** (черновики, настройки). Экспорт/импорт `.lua`.
- Окружение: Windows, любой современный браузер. Без Node/Python в рантайме.

## 3. Команды
- Запуск: открыть `index.html` двойным кликом (или `start.bat`).
- Тестов нет (статический фронтенд); проверка — ручной прогон сценариев (см. чек-лист).

## 4. Структура проекта
```
LUA Stormworks/
  index.html            — интерфейс, все вкладки
  start.bat             — запуск через локальный сервер (опционально)
  README.md             — инструкция
  SPEC.md               — этот файл
  css/style.css         — тема оформления
  css/libs/*.css        — стили CodeMirror
  js/libs/*.js          — CodeMirror + дополнения, fengari-web
  js/stormworks.js      — эмуляция API Stormworks + мост к Lua-ВМ
  js/minify.js          — минификатор Lua
  js/uibuilder.js       — визуальный конструктор экранов
  js/app.js             — связка интерфейса, запуск, хранение, вкладки
  data/docs-ru.js       — справочник API на русском
  data/examples-ru.js   — примеры скриптов
  data/tutorials-ru.js  — уроки
```

## 5. Границы (✅ / ⚠️ / 🚫)
- ✅ Всегда: русский язык интерфейса; работа офлайн; комментарии в примерах на русском.
- ⚠️ Спросить: менять состав глобальных объектов API; ломать формат ссылки-шаринга.
- 🚫 Никогда: не требовать сервер/интернет; не подключать внешние CDN в рантайме;
  не выполнять пользовательский код дольше лимита инструкций (риск зависания).

## 6. Данные и модель
- `Runtime`: каналы `input`(1..32), `output`(1..32), `property` (label→значение), счётчик тиков.
- `SWScreen`: canvas 2D, набор методов `screen.*` (draw*, setColor, drawMap, getWidth...).
- `LUNA_DOCS[]`, `LUNA_EXAMPLES[]`, `LUNA_TUTORIALS[]` — контент (грузится как JS-глобалы).
- `localStorage` ключи: `luna.settings`, `luna.autosave`, `luna.drafts`.
