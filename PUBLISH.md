# Публикация Луна IDE — что где лежит

Всё, что нужно для выкладки в интернет, собирается одной командой:

```bat
npm run installer      :: собрать установщик  -> release\Luna-IDE-Setup-1.1.0.exe
npm run shots          :: снять скриншоты    -> publish\shots\*.png
npm run images         :: обложки нужных размеров (itch/site)
npm run release-files  :: собрать publish\web\ и publish\itch\
npm run hosting        :: publish\hosting\ — лендинг + установщик в ОДНОЙ папке (РФ-хостинг)
npm run github         :: publish\github\ — готовый репозиторий для GitHub
npm run check-hosting  :: проверить папку как посетитель (через http://)
```

## Что получается

```
release\
  Luna-IDE-Setup-1.1.0.exe      установщик для Windows (~99 МБ)

publish\
  web\                          готовая веб-версия (index.html в корне)
  itch\
    Luna-IDE-Setup-1.1.0.exe    то же, для загрузки на itch.io
    luna-ide-web-1.1.0.zip      веб-версия архивом (играется в браузере на itch.io)
    cover.png                   630×500 — обложка проекта
    screenshots\                5 скриншотов интерфейса
    page.md                     готовое описание (RU + EN) и чек-лист публикации
  site\                         лендинг проекта (index.html + hero + shots)
    app\                        веб-версия внутри лендинга (кнопка «Открыть веб-версию»)
  shots\                        все снятые скриншоты
```

Лендинг (`site\`) и веб-версию (`web\`) публикуют перетаскиванием папки,
установщик отдают через itch.io.

## 1. Веб-версия на Netlify Drop (без регистрации и без git)

1. Открыть <https://app.netlify.com/drop>.
2. Перетащить папку `publish\web` в окно браузера (именно папку, не архив).
3. Через несколько секунд Netlify даст адрес вида `https://что-то.netlify.app`.
4. Скопировать адрес — он понадобится в лендинге (`LINKS.webUrl`).
5. Чтобы адрес не менялся при обновлениях, создать бесплатный аккаунт Netlify и привязать сайт к нему.

Альтернативы: **Cloudflare Pages** (Direct Upload), **GitHub Pages** (нужен git).

## 2. Проект на itch.io

Пошаговый чек-лист и тексты описания — в `publish\itch\page.md`.
Коротко: создать проект → тип **Tools** → загрузить `Luna-IDE-Setup-1.1.0.exe`
(Windows) и `luna-ide-web-1.1.0.zip` (галочка «played in the browser») →
обложка `cover.png` и скриншоты → **Public** → **Save & view page**.

itch.io — то место, откуда скачивают **установщик** (99 МБ). Именно поэтому его
не кладём на статический хостинг: у Netlify/Cloudflare есть ограничения на размер
файла, а itch.io для больших сборок и сделан.

## 3. Лендинг

`publish\site\` — **самодостаточная папка**: страница + `hero.png` + `favicon.png` +
`shots\` + `app\` (внутри — сама веб-версия). Внешних зависимостей нет,
всего ~2 МБ.

- Посмотреть локально: двойной клик по `publish\site\index.html`.
- **Опубликовать:** открыть <https://app.netlify.com/drop> и перетащить **папку**
  `publish\site` в окно браузера. Через несколько секунд появится адрес вида
  `https://что-то.netlify.app` — он и есть публичная ссылка на лендинг.
- Кнопка «Открыть веб-версию» сразу ведёт на `app/index.html` — работает без
  всякой настройки. Кнопка «Скачать для Windows» пока приглушена; она включится,
  когда вы впишете адрес страницы itch.io.

После публикации itch-страницы откройте `publish\site\index.html` и заполните
ссылку в блоке `LINKS` (внизу файла):

```js
var LINKS = {
  itchUrl: 'https://starichek.itch.io/luna-ide',   // откуда качают установщик
  webUrl:  'app/index.html'                        // веб-версия внутри лендинга
};
```

Пока `itchUrl` пуст — кнопка скачивания показана как «— скоро», а главной
кнопкой на странице делается рабочая «Открыть веб-версию».

Аккаунт на Netlify заводить не обязательно (drop без логина работает), но
**без аккаунта сайт нельзя потом обновить и адрес может измениться** — для
постоянной публикации лучше зарегистрироваться бесплатно и «присвоить» сайт.

Альтернативы Netlify: **Cloudflare Pages** (Direct Upload; лимит 25 МБ на файл —
для лендинга не важно, установщик всё равно на itch.io), **GitHub Pages**
(файлы можно загрузить прямо в браузере, без установки git).

## 4. Свой хостинг в РФ (лендинг + установщик в одном месте)

Нужен, если хочется один адрес и российскую оплату, а не itch.io + Netlify по отдельности.

```bat
npm run hosting
```

Собирает `publish\hosting\` — это **готовая папка сайта**:

```
publish\hosting\
  index.html                    лендинг
  Luna-IDE-Setup-1.1.0.exe      установщик (~99 МБ) — качается прямо с сайта
  app\                          веб-версия (кнопка «Открыть веб-версию»)
  shots\, hero.png, favicon.png
```

Всего ~101 МБ. Дальше — как на любом виртуальном хостинге: зайти в панель →
файловый менеджер (или FTP/SFTP) → залить **содержимое** `publish\hosting\`
в корень сайта (`public_html`, `www`, `htdocs` — название зависит от хостера).

Кнопка «Скачать для Windows» включает себя **сама**: страница проверяет, лежит ли
рядом файл установщика, и если да — активирует кнопку на `Luna-IDE-Setup-1.1.0.exe`.
Если файла нет (например, на Netlify) — кнопка остаётся в режиме «скоро».
Проверено в обоих режимах: `npm run check-hosting`.

### Куда именно (варианты по РФ)

| Площадка | Что даёт | Нюансы |
|---|---|---|
| **Timeweb** — виртуальный хостинг | Лендинг + установщик, бесплатный SSL (Let's Encrypt), неограниченный трафик, 10 дней бесплатно; по акции — домен `.RU` в подарок при оплате за год | Классический вариант «под ключ», ничего настраивать не нужно |
| **Beget** — виртуальный хостинг | То же + 30 дней бесплатной пробной эксплуатации, файловый менеджер, SSH/SFTP | По правилам запрещены *файлообменники и массовая раздача* — **свой** установщик на своём сайте это не нарушает |
| **Sprinthost / reg.ru / hostland** | Аналог: виртуальный хостинг с SSL и файловым менеджером | Сравнить лимиты по нагрузке на процессор |
| **Timeweb Cloud — объектное хранилище (S3)** | Только файлы. Хранение ≈2 ₽/ГБ, исходящий трафик ≈1,3 ₽/ГБ (первые ~100 ГБ/мес бесплатно) | Дешевле всего, если раздача установщика станет большой; лендинг тогда отдельно |
| **Yandex Object Storage / Selectel** | S3 с поддержкой статического сайта из бакета | Больше ручной настройки (домен, SSL, CORS) |

Цены и условия акций меняются — **проверяйте на сайте площадки на дату покупки**.

Практический совет: начните с **виртуального хостинга** (проще всего: домен, SSL,
файлы и установщик в одном месте). Объектное хранилище подключайте позже — если
скачиваний станет много и упрётесь в лимиты хостинга.

### Что важно про раздачу .exe

- Браузер не скачает установщик «молча» — это нормально, так и должно быть.
- Windows покажет SmartScreen («Неизвестный издатель»): у программы нет платной
  цифровой подписи. Это описано на лендинге, чтобы пользователи не пугались.
- Проверьте, что по адресу файла отдаётся **200** и полный размер:
  `npm run check-hosting` (локально) или откройте ссылку в браузере после загрузки.

## 5. GitHub (код + Releases + GitHub Pages)

Что получается: исходники в репозитории, установщик — в **Releases**, страница
проекта — на **GitHub Pages**. Git на компьютер ставить не нужно: всё делается
через браузер.

```bat
npm run github
```

Собирает `publish\github\` — готовый репозиторий (87 файлов, ~7 МБ):
исходники, `tools\`, `docs\` (страница + веб-версия в `docs\app`), `LICENSE`,
`.gitignore`, `.github\workflows\`, `PUBLISH.md`.
Тяжёлых файлов там нет: `.exe` распространяется через Releases.

### Шаги

1. Создать аккаунт на github.com.
2. **New repository** → имя `luna-ide` → тип **Public** (для бесплатного Pages) →
   не добавлять README/LICENSE (они уже есть в папке).
3. На странице пустого репозитория: **Add file → Upload files** → перетащить
   **содержимое** `publish\github\` (файлы и папки, но не саму папку `github`) →
   сообщение коммита → **Commit changes**.
   Если браузер не примет всё сразу — залить в два приёма: сначала папку `docs`,
   затем остальное.
4. **Установщик.** Вкладка **Releases** → **Create a new release** → тег `v1.1.0` →
   **Publish release**. Дальше два пути:
   - **Автоматически:** workflow `.github/workflows/build-release.yml` соберёт `.exe`
     на серверах GitHub и приложит его к релизу (5–10 минут; следить в разделе
     **Actions**). В релизе появится файл `Luna-IDE-Setup.exe` — имя постоянное,
     чтобы ссылка на скачивание не менялась между версиями.
   - **Вручную и быстро:** приложить к релизу готовый `release\Luna-IDE-Setup-1.1.0.exe`
     через «Attach binaries», а сам workflow не использовать (тогда скопируйте файл
     под именем `Luna-IDE-Setup.exe`, чтобы ссылка совпала).
5. **Страница.** Settings → **Pages** → Source: *Deploy from a branch* →
   Branch `main`, папка **/docs** → **Save**. Через минуту страница откроется по адресу
   `https://ПОЛЬЗОВАТЕЛЬ.github.io/luna-ide/`.
6. Кнопка «Скачать для Windows» на странице включится **сама**: лендинг определяет
   адрес релиза по домену `*.github.io` (прописывать ничего не нужно).

### Важные детали

- **Установщик в репозиторий не кладём.** GitHub не принимает в репозиторий файлы
  больше 100 МБ, а в Releases — до 2 ГБ. Поэтому `.exe` живёт только в Releases.
- **Публичный репозиторий** нужен для бесплатного GitHub Pages.
- Ссылка вида `https://github.com/ПОЛЬЗОВАТЕЛЬ/luna-ide/releases/latest/download/Luna-IDE-Setup.exe`
  работает всегда и не зависит от номера версии — этим и пользуется лендинг.
- Если в Actions сборка упала — не страшно: соберите локально `npm run installer`
  и приложите файл к релизу вручную.

## Что обновлять при новой версии

1. Поднять `version` в `package.json`.
2. `npm run installer`, затем `npm run release-files` и `npm run hosting`
   (последний заодно обновит `site\app\` и положит новый `.exe`).
3. Заменить файлы на itch.io (загрузить новую версию тем же именем).
4. Перетащить папку `publish\site` на Netlify Drop заново (обновится и лендинг, и веб-версия).
5. На своём хостинге — перезалить файл установщика и `index.html`.
6. GitHub: `npm run github` → залить изменения в репозиторий (Upload files) → создать
   новый релиз с тегом `vX.Y.Z` (установщик соберётся и приложится сам).
7. Поправить номер версии в `publish\site\index.html` (упоминается 3 раза), в `LINKS.installer`,
   в названии файла `publish\hosting\` и в README.
