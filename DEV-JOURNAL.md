# Журнал проекта — Луна IDE

Среда разработки Lua для микроконтроллеров Stormworks (RU, офлайн).
Автор: СтаричЁк. Папка: `C:\Users\vikto\OneDrive\Рабочий стол\LUA Stormworks`.

## Статус

- Версия **1.1.0**. MVP закрыт, приложение работает (настольное + веб).
- Код Lua исполняется по-настоящему (Fengari Lua 5.3), виртуальный монитор,
  справочник/уроки/примеры на русском, конструктор UI, минификатор с лимитом 8192.

## Что сделано 2026-10-04 — подготовка к публикации

1. **Установщик Windows (NSIS).** Добавлен `electron-builder@25.1.8`.
   Команда `npm run installer` → `release\Luna-IDE-Setup-1.1.0.exe` (98,8 МБ).
   Настройки в `package.json` → `build`. Ярлык «Луна IDE», выбор папки установки,
   русский язык установщика. Собранный `.exe` проверен запуском (процесс живёт,

   Проверка `npm run check-web`: открывает собранную веб-версию в Chromium,
   запускает пример — вывод «консоль: …привет из веб-версии», «монитор: 160x96,

4. **Скриншоты.** `npm run shots` — Electron-скрипт `tools/shots.js` снимает
   5 экранов (редактор с работающим спидометром на мониторе, примеры,

8. **Лендинг сделан автономным.** Веб-версия копируется внутрь лендинга
   (`publish\site\app\`) — «Открыть веб-версию» работает относительной ссылкой

   `check-web` по `publish\site\app\index.html` → **OK**.
   Кнопка «Скачать для Windows» ссылается на itch.io; пока адрес не задан,
   она приглушена («— скоро»), а главной кнопкой становится рабочая веб-версия —

9. **Комплект под свой хостинг (РФ).** `npm run hosting` собирает
   `publish\hosting\` (лендинг + установщик рядом + `app\`) — 100,9 МБ, заливается

   Проверено `npm run check-hosting` через локальный HTTP:
   с файлом — «кнопка включена, файл 200, 98,8 МБ»; без файла — «режим скоро».
   Оба режима — OK.
10. **Комплект для GitHub.** `npm run github` собирает `publish\github\` — готовый
   репозиторий (87 файлов, 7,0 МБ): исходники, `tools\`, `build\`, `docs\` (страница

11. **Лендинг сам находит релиз.** На GitHub Pages адрес установщика определяется
   по домену `*.github.io` → `https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ/releases/
   latest/download/Luna-IDE-Setup.exe`. Логику вывода адреса проверил на 6 примерах
   (github.io с подпапкой, свой домен, file://, явная ссылка). В workflow добавлено
   дублирование установщика под постоянным именем `Luna-IDE-Setup.exe` — чтобы
   ссылка на скачивание не менялась между версиями. Установщик в репозиторий
   не коммитим: там лимит 100 МБ на файл, а в Releases — 2 ГБ.

## Решения

- **Дистрибутив — NSIS-установщик, а не только portable-папка.** Пользователю
  проще «скачал → установил → ярлык», чем распаковывать 350 МБ.
- **Веб-версию раздаём через Netlify Drop** (без git и регистрации) — у
  пользователя git не установлен, а GitHub Pages его требует.
- **itch.io — основная площадка** публикации: заточена под игры/моды, бесплатна,
  умеет и скачиваемый `.exe`, и веб-версию на странице.
- **favicon и `build/icon.png` держим в `build.files`** — иначе Electron их
  не пакует (проверено).

## Открытые вопросы

- Сборка идёт с неподписанным `.exe` → SmartScreen. Сертификат code signing
  не покупаем (платно), предупреждение объясняем в инструкции и на лендинге.
- Папка `dist\` (portable, версия 1.0.0) устарела и весит ~350 МБ —
  решить, удалять ли её (установщик её заменяет).

## Что дальше

1. **Лендинг:** перетащить папку `publish\site` на <https://app.netlify.com/drop> →
   получить публичный адрес. Работает сразу (веб-версия внутри).
2. Опубликовать `publish\itch` на itch.io → адрес страницы вписать в `LINKS.itchUrl`
   в `publish\site\index.html` (тогда включится кнопка скачивания).
3. Анонс в сообществах Stormworks (Discord/VK), ссылка на лендинг/itch.io.
4. При желании — автообновление версии (electron-updater), скриншот-тур, GIF.

## Технические заметки

- Node 20.11 → Electron **41** (42+ не ставится), `@electron/packager` 18,
  `electron-builder` 25.1.8. Всё совместимо.
- `npx electron …` в PowerShell иногда падает с `UnknownVizError` — запускать
  `.\node_modules\electron\dist\electron.exe` напрямую (так работают `npm run shots`).
- Скриншот-скрипты: `app.disableHardwareAcceleration()` + обработчик
  `window-all-closed` (иначе Electron выходит после закрытия первого окна).
- Лимит кода 8192 символа; кириллица в экранном тексте запрещена (шрифт игры).
