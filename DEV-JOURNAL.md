# Журнал проекта — Луна IDE

Среда разработки Lua для микроконтроллеров Stormworks (RU, офлайн).
Автор: СтаричЁк. Папка: `C:\Users\vikto\OneDrive\Рабочий стол\LUA Stormworks`.

## Статус

- Версия **1.1.0**. MVP закрыт, приложение работает (настольное + веб).
- Код Lua исполняется по-настоящему (Fengari Lua 5.3), виртуальный монитор,
  справочник/уроки/примеры на русском, конструктор UI, минификатор с лимитом 8192.

## Решения

- **Дистрибутив — NSIS-установщик, а не только portable-папка.** Пользователю
  проще «скачал → установил → ярлык», чем распаковывать 350 МБ.
- **Веб-версию раздаём через Netlify Drop** (без git и регистрации) — у
  пользователя git не установлен, а GitHub Pages его требует.
- **itch.io — основная площадка** публикации: заточена под игры/моды, бесплатна,
  умеет и скачиваемый `.exe`, и веб-версию на странице.
- **favicon и `build/icon.png` держим в `build.files`** — иначе Electron их
  не пакует (проверено).

## Открытые вопросы

- Сборка идёт с неподписанным `.exe` → SmartScreen. Сертификат code signing
  не покупаем (платно), предупреждение объясняем в инструкции и на лендинге.
- Папка `dist\` (portable, версия 1.0.0) устарела и весит ~350 МБ —
  решить, удалять ли её (установщик её заменяет).

## Ширина панели и анимация входов (2026-10-27)

1. **Правая панель тянется мышью.** Между редактором и `.side-col` вставлен
   `.side-resizer` (`#sideResizer`); ширина считается от правого края `.editor-wrap`,
   ограничение 300 px…70 % окна (и не уже, чем окно минус 360 px под редактор),
   двойной клик — сброс на 470. Ширина сохраняется в `settings.sideWidth`.
   Пришлось поднять `.side-col { max-width }` с 46vw до 70vw — иначе ползунок
   упирался в процент и панель не расширялась. На узких экранах (≤900 px) ползунок
   скрыт, панель как раньше — 100 % ширины.
2. **Анимация числовых входов композита.** У числового входа появилась галочка
   «анимация»: раскрывается строка `мин / макс / шаг`, поле значения становится
   только для чтения и показывает текущее число. Движение — маятник
   (мин → макс → мин), шаг ровно за один тик; старт вместе с «Запустить», при каждом
   запуске снова с минимума. Галочка снята — в код идёт точное значение, никаких
   изменений. Логика в `advanceAnim()` (`js/app.js`), вызывается из `loop()` и `step()`
   перед `onTick`; значения живут в `ioAnim` по индексу записи.
   *Решение:* кнопку запуска не делали — владелец попросил совместить в одну галочку;
   галочка = и режим, и взвод, а тикает только при запущенном скрипте.
   Попутно «точное значение» стало сохраняться (`settings.io[i].value`) — раньше
   сбрасывалось в 0 при перерисовке панели. Старые сохранения нормализуются
   `ioNorm()`, `settings._v = 3`.
3. **Проверка.** Новый `npm run check-anim` (`tools/check-anim.js`): точное значение 7 →
   выход 7; при анимации 0…4 шагом 1 отсчёты по «Шаг» дают 2,3,4,3,2,1,0,1,2,3

## Версия 1.3.0: автообновление и публикация (2026-10-27)

1. **Автообновление подключено.** `electron-updater@6` + `build.publish` (GitHub,
   `Bossmen007/Luna-IDE-LUA-Stormworks`). electron-builder кладёт в приложение
   `app-update.yml` и в `release/` — `latest.yml`. В `electron-main.js` — тихая проверка
   через 3 с после старта, `autoDownload=false`: сначала пользователь видит
   «Доступна версия X» и жмёт «Скачать», затем «Перезапустить и обновить».
   В `preload.js` — шесть команд `update:*`, в настройках — карточка «Обновления»
   (версия, статус, чекбокс «Проверять при запуске», кнопки).
   *Решение:* без модалок при старте — чтобы офлайн-запуск не выглядел ошибкой.
   В режиме разработки карточка пишет, что проверка работает только в установленной версии.
2. **Релиз теперь из трёх файлов:** `Luna-IDE-Setup-<версия>.exe` (его качает апдейтер,
   имя берётся из `latest.yml`), `latest.yml` и копия `Luna-IDE-Setup.exe` для постоянной
   ссылки сайта; плюс `*.blockmap` для докачки. `fixasset` больше не удаляет версионный
   файл — keep-list. Старое правило «ровно один exe» заменено, иначе автообновление
   не находит файл.
   *Замечание:* установщик заливается дважды (99 МБ ×2) — так проще, чем переименовывать
   ассет через API; время релиза ~4–6 минут.
3. **Проверки:** `npm run check-update` (карточка, все состояния, отсутствие в веб-версии),
   `npm run check-anim` (анимация и ширина панели), `check-io`, `check-ui` — все OK.
   `latest.yml` проверен: версия 1.3.0, sha512 и размер совпадают с exe;
   `node_modules/electron-updater` внутри `app.asar`.
4. **Важно для будущих версий:** поднимать версию в пяти местах (см. HANDOVER раздел 6),
   собирать `npm run installer` (появится новый `latest.yml`), затем
   `release-files → github → gh-upload → gh-release`. Установленные 1.2.0 и ниже
   обновиться сами не смогут — им нужна одна ручная установка 1.3.0.
