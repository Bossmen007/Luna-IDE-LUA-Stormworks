Исполнение

Если скрипт содержит бесконечный цикл, IDE прервёт его после указанного числа шагов.

Лимит размера скрипта в игре: 8192 символа. Учитываются все символы — буквы, знаки, пробелы, переводы строк и комментарии. Счётчик показан в панели редактора.

Поддержать проект

Основной способ — ЮMoney, кошелёк 4100119229429725. Он уже встроен: кнопка «💛 Поддержать» в шапке открывает окно с благодарностью и переводом.

Публикуется только номер кошелька — это публичный адрес для переводов, а не карта. Реквизиты карт и личные данные в приложении не хранятся, статистика не собирается.

О программе

«Луна IDE» — русский редактор Lua для Stormworks. Работает полностью офлайн. Lua исполняется движком Fengari (Lua 5.3), редактор кода — CodeMirror 5.

Разработчик: СтаричЁк.

Новости и обновления — Telegram-канал: t.me/luna_ide.

Это неофициальный инструмент, не связанный с разработчиками Stormworks. Имена функций API проверяйте в игре.
