# История изменений — Луна IDE

## v1.2.0

### Новое
- **Конструктор экранов доведён до полноценного состояния.**
  20 видов элементов: текст, прямоугольник, круг, кнопка, фиксатор, тумблер (вертикальный
  и горизонтальный), лампа-индикатор (круг и квадрат), полоса, шкала (горизонтальная и
  вертикальная), диал (180° и 270°), график (линия, заливка, столбики), 7-сегментный
  индикатор, сегментный индикатор, батарея на 8 сегментов.
- **Диапазон и цвета по значению.** У элементов со значением задаётся Мин/Макс, пороги
  цвета (доли 0..1), флаг «Инверсия» (для батареи: меньше заряда — тревожнее).
- **Привязка к каналам композита.** Числовой или логический вход (1–32) либо постоянное
  значение; у интерактивных элементов — выход.
- **Генерация готового Lua-кода** (`onTick` + `onDraw`) с хелперами и счётчиком длины,
  который предупреждает, если код превышает игровой лимит 8192 символа.
- **Копирование и вставка стиля** элемента, набор цветовых тем оформления приборной панели,
  перетаскивание элементов мышью, стрелки для точного сдвига, Delete для удаления.
- **Автоопределение сигналов композита.** Кнопка «⟳ Из кода» и автопоиск при открытии
  вкладки «Композит»: находит `input.getNumber/getBool`, `output.setNumber/setBool`,
  подставляет имена из `local имя = input.getNumber(n)` и показывает список локальных
  переменных. Ручные сигналы сохраняются.
- **Кнопка Telegram** в шапке программы — переход в канал проекта: https://t.me/luna_ide

### Проверки
- `node tools/check-builder.js` — все 20 элементов: сгенерированный код компилируется
  и выполняется (Fengari Lua 5.3).
- `node tools/check-io.js` — автоопределение входов/выходов/локальных переменных.

## v1.1.0

- Установщик Windows (NSIS), веб-версия и лендинг.
- Реальный интерпретатор Lua 5.3 (Fengari), виртуальный монитор, клик по экрану = сенсор.
- Справочник API и уроки на русском, 13 примеров.
- Минификатор и лимит 8192 символа.
- Черновики, экспорт/импорт `.lua`, ссылка-шаринг.
- Публикация на GitHub (Pages + релиз), комплекты для itch.io и РФ-хостинга.
